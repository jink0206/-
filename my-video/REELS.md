# 릴스 오버레이 팩 (남편의 리뷰생활)

촬영한 영상 위에 얹어 쓰는 스티커(PNG)와, 영상 맨 끝에 붙이는 엔딩카드(MP4)입니다.
색과 폰트는 카드뉴스 템플릿과 같습니다. (노랑 `#FFC93C` / 네이비 `#1B2A41` / 크림 `#FFF8E7`)

## 파일 구성 (`out/` 폴더)

| 폴더 | 파일 | 쓰는 곳 |
|---|---|---|
| `stickers/` | `판결-재방문-O/X.png`, `판결-구매추천-O/X.png` | 마지막 장면에 얹는 판결 도장 |
| `stickers/` | `칩-웨이팅-있음.png` 외 8종 | 웨이팅·주차·혼밥 등 조건 라벨 |
| `endcards/` | `엔딩카드-재방문-O/X.mp4`, `엔딩카드-구매추천-O/X.mp4` | 릴스 맨 끝에 붙이는 3초 영상 |
| `post/` | `훅-○○.png`, `가격-○○.png` | 게시물마다 문구가 다른 훅 자막, 메뉴·가격 라벨 |

모든 PNG는 **투명 배경**이라 영상 위에 그대로 얹으면 됩니다. 엔딩카드는 1080×1920(릴스 세로 규격)입니다.

## 쓰는 법 (캡컷·인스타 편집기 공통)

1. 촬영한 클립을 이어 붙입니다. (15~20초)
2. 첫 3초: `훅` PNG를 위쪽에 얹습니다. 화면 위아래 약 250px는 인스타 UI에 가려지니 피하세요.
3. 메뉴 컷마다 `가격` PNG를 아래쪽에 얹습니다.
4. 조건 라벨(`칩-…`)을 필요한 컷에 얹습니다. (웨이팅 컷에 `웨이팅 있음` 등)
5. 맨 끝에 `엔딩카드` MP4를 붙입니다. (재방문 O/X 중 하나만 고르세요)

## 게시물마다 새로 만들기 (훅, 가격)

`data/post.json`을 아래 형식으로 만들고 실행합니다.

```json
{
  "hooks":  [ { "file": "칼국수", "text": "9,000원에\n이게 다 나온다고?" } ],
  "prices": [ { "file": "칼국수", "name": "칼국수", "price": "9,000원" } ]
}
```

```bash
cd my-video
npm ci
node scripts/render-pack.mjs post data/post.json   # → out/post/
node scripts/render-pack.mjs pack                  # 고정 스티커·엔딩카드 전체 다시 만들기
```

훅 문구는 줄바꿈(`\n`)으로 두 줄까지 쓰는 것을 권장합니다. 글자 수에 따라 크기가 자동으로 줄어듭니다.

## 스티커 추가·수정

- 고정 스티커와 엔딩카드 목록은 `src/catalog.json` 한 곳에서 관리합니다.
- 디자인은 `src/Sticker.tsx`, `src/EndCard.tsx`, `src/PostOverlays.tsx`에 있습니다.
- 미리보기: `npm run dev` (Remotion Studio)
