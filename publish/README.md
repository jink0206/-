# JIN:ON 발행 패키지 v3

- **릴스 20편**: 소리 없는 영상(15~18초, 글이 한 줄씩 나타남) + 표지 이미지. 음악은 인스타 앱에서 붙입니다.
- **캐러셀 5편**(주 1회): 첫 장에서 답을 주지 않고 넘기게 만드는 구성. 나머지 15편 이미지는 `carousel_bank/`.
- **성장 로드맵**: `ROADMAP.md` (폰 가이드 페이지의 '성장 로드맵' 탭에도 있어요)

## 폰으로 올리는 순서

1. `publish/phone/` 파일 이름 맨 앞 숫자(01~25)가 올리는 순서입니다.
2. **릴스**: `NN_날짜_릴스_epNN.mp4`를 올리고 → 앱에서 음악 추가 → 표지는 `…_표지.png` 선택 → 캡션은 `epNN/post_reel.txt`
3. **캐러셀**: `…_캐러셀_epNN_1ofM`부터 번호 순서대로 선택 → 캡션은 `epNN/post_carousel.txt`
4. 폰 가이드 페이지에서 영상 미리보기, 이미지 저장, 캡션 복사, 체크를 할 수 있어요.

| 위치 | 내용 |

## 바뀐 점 (v2 → v3)
- 녹음 없이 음악 + 영상으로: 대본 낭독용 파일(SRT, 낭독 대본)은 정리했습니다.
- 릴스 표지: 영어 인용(작게) → 후킹(크게) → 한글 대본 순서. 영상 마지막 장면과 같습니다.
- 캐러셀 첫 장 문구 20개를 모두 다르게 다시 썼습니다("그런데 아니었다" 반복 제거).
- 일정: 릴스 주 3회 → 4회, 캐러셀 주 3회 → 1회. 내 계정 데이터에서 캐러셀 조회가 0~2회였기 때문입니다.
