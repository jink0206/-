## 캐러셀 구성 (3:4, 샘플 디자인)

- 2~마지막 전 장: 장마다 하단에 "2 / 5 →" 같은 쪽수와 다음 장 표시. 2장 명언 + 발언자, 3~4장 장면·반전

- 마지막 장: 크림 배경, 마지막 문장 + "힘든 날 꺼내 볼 수 있게 저장해 두세요" + 큰 로고
