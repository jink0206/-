# JIN:ON 발행 패키지 v4

- **릴스 40개**(주 6회): 20편 × 후킹 A·B 두 버전. 소리 없는 영상(15~18초, 글이 한 줄씩 나타남) + 표지. 음악은 인스타 앱에서 붙입니다.
- **캐러셀 20개**(주 4회): 첫 장에서 답을 주지 않고 넘기게 만드는 구성.
- **성장 로드맵**: `ROADMAP.md` (폰 가이드 페이지의 '성장 로드맵' 탭에도 있어요)

## 폰으로 올리는 순서

1. `publish/phone/` 파일 이름 맨 앞 숫자(01~60)가 올리는 순서입니다. 같은 날 2개면 캐러셀(낮) → 릴스(밤) 순서예요.
2. **릴스**: `NN_날짜_릴스_epNNA.mp4`(또는 B)를 올리고 → 앱에서 음악 추가 → 표지는 `…_표지.png` → 캡션은 `epNN/post_reel_A.txt`(또는 B)
3. **캐러셀**: `…_캐러셀_epNN_1ofM`부터 번호 순서대로 → 캡션은 `epNN/post_carousel.txt`
4. 폰 가이드 페이지에서 저장 버튼, 캡션 복사, 체크를 할 수 있어요.
