# 훅 공식

첫 1~3초의 화면 자막 + 음성. **필요한 사실이 확인되지 않으면 쓰지 않는다.**
근거 수준: ★★★ 분석한 릴스에서 직접 확인 / ★★ 같은 패턴을 응용 / ★ 데이터 부족, 가설

## 식당

| # | 공식 | 틀 (자막 / 음성) | 필요한 사실 | 근거 |
|---|---|---|---|---|
| R1 | 가격·양 놀람 | "[가격]원에 이게 다 나온다고?" / "[가격]원밖에 안 해요" | 가격, 구성 | ★★★ |
| R2 | 수치 증명 | "무려 [수치]나 들어가서 [가격]원" | 양(g, 개 등)과 가격 | ★★★ |
| R3 | 웨이팅 증거 | "[날씨·요일]에도 줄 서는 [지역] [메뉴]집" | 실제로 줄 선 장면 | ★★★ |
| R4 | 발견 선언 | "[지역]에서 [수식어] [메뉴]집을 발견했습니다" | 지역 특성, 사용자의 감상 | ★★★ |
| R5 | 점수제 | "[소문·추천]난 [지역] [메뉴]집, 제 점수는 과연...?" | 소문·추천 출처 | ★★★ |
| R6 | 질문형 | "이게 다 나온다고?" / "여긴 얼마나 맛있길래?" | 푸짐한 구성 또는 긴 줄 | ★★★ |
| R7 | 솔직형(기본) | "[메뉴], 눈치 안 보고 솔직하게 평가합니다" | 없음 (항상 가능) | ★★ 계정 컨셉 |
| R8 | 정보 선두 | "[지역] [메뉴]집, 웨이팅 [시간]" | 웨이팅 시간 | ★★★ |

### 수식어 후보 (감상이 확인된 경우에만)
엄청난 / 푸짐한 / 인생 [메뉴] / 줄 서는 / 가성비 / 노포

## 제품

| # | 공식 | 틀 | 필요한 사실 | 근거 |
|---|---|---|---|---|
| P1 | 가격 놀람 | "[가격]원짜리가 이 정도?" | 가격, 실제 사용 결과 | ★★ |
| P2 | 사용기 선언 | "[기간] 써보고 솔직하게 말합니다" | 사용 기간 | ★★ |
| P3 | 점수제 | "[제품명], 제 점수는 과연...?" | 점수 항목 | ★★ |
| P4 | 질문형 | "이게 [가격]원이라고?" | 가격 | ★★ |
| P5 | 비교형 | "[A] vs [B], 직접 써보고 비교" | 두 제품 모두 사용 | ★ |
| P6 | 가족·일상 | "저희 남편이 [기간] 써본 [제품]" | 실제 사용 | ★ 소형 계정 사례에서 가정형 말투가 반응 좋음 |

정보와 제품은 분석한 릴스가 주로 식당이라 근거가 약하다. 처음 몇 편은 반응을 보고 공식을 조정한다.

## 훅 점검표 (출력 전)
- [ ] 자막이 1초 안에 읽히는 길이인가 (한 번에 1~3단어)
- [ ] 영상에서 첫 컷으로 증명되는가 (가격표, 줄, 푸짐한 한 상)
- [ ] 사실이 확인된 것만 들어갔나
- [ ] 과장·허위 소지가 없나
