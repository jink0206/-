# 훅 공식

종류: 식당(R) · 제품(P) · 정보(I) · 꿀팁(T)

첫 1~3초의 화면 자막 + 음성. **필요한 사실이 확인되지 않으면 쓰지 않는다.**
근거 수준: ★★★ 분석한 릴스에서 직접 확인 / ★★ 같은 패턴을 응용 / ★ 데이터 부족, 가설

### 정보 훅 규칙
- **첫 자막에 기간 또는 가격 숫자가 들어간다.** (이번 주 일요일까지 / 9,900원 / 300원부터)
- "공짜", "단 하루" 같은 말은 **공식 안내로 확인된 경우에만** 쓴다.
- 광고·협찬이면 첫 자막이나 캡션에 표기한다. (분석한 사례 중 "광고아님" 표기 사례도 있다)

## 꿀팁 (생활·사용법·비추천)

2026-11 아웃라이어 + 장면 분석 2개 기반. 팔로워 500~1.5만 계정이 100만 조회 이상을 낸 사례가 있다.

| # | 공식 | 틀 (자막 / 음성) | 필요한 사실 | 근거 |
|---|---|---|---|---|
| T1 | 경고형 | "[행동] 절대 하지 마세요" / "[A]하면 안 됩니다!" + 구체적 이유 | 직접 겪은 문제, 증거 영상 | ★★★ 다이소 치실 180만 |
| T2 | 검증형 | "[방법]? 진짜 될까?" → 시도 → 결과 반전 | 실제로 해본 결과 | ★★★ 밤껍질 130만 (532명 계정) |
| T3 | 공감 질문형 | "[불편한 상황] 겪어본 적 있나요?" | 흔한 불편, 해결 시연 | ★★ 롱패딩 보관 9만 |

| T8 | 단 하나형 | "[결과] 비법, 단 1가지!" / "세제만 넣고 돌리면 안 됩니다!" | 방법 | ★★ 이불 세탁 9만 |

### 꿀팁 훅 규칙
- **직접 해본 것만** 쓴다. 해보지 않은 방법을 "된다"고 말하지 않는다.
- 비추천(T1)은 **내돈내산 + 구체적 사용 경험 + 사실**만. 상표나 가게 비방, 과장 표현은 쓰지 않는다. 문제가 재현되지 않았다면 쓰지 않는다.
- 건강·안전·법률·약 관련 꿀팁은 **공식 근거를 확인**하고, 위험한 행동을 권하지 않는다.
- 검증형(T2)은 **실패해도 그대로** 올린다. 결과 판결로 "성공 O / 실패 X"를 쓴다.

## 훅 점검표 (출력 전)
- [ ] 자막이 1초 안에 읽히는 길이인가 (한 번에 1~3단어)
- [ ] 영상에서 첫 컷으로 증명되는가 (가격표, 줄, 푸짐한 한 상)
- [ ] 사실이 확인된 것만 들어갔나
- [ ] 과장·허위 소지가 없나
