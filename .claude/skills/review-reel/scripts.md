# 대본 구조 6종

공통 규칙
- 길이 15~20초 (정보량이 많으면 최대 35초). 컷은 1~3초.
- 자막은 한 번에 1~3단어, 약 1초마다 교체. 화면 위·아래 약 250px는 비운다.
- 가격·양·웨이팅은 **숫자로** 보여 준다. 실용 정보는 단문 자막(칩 스티커 활용).
- 마지막: 총평 한 줄 → `판결 도장` → `엔딩카드`.
- 각 구조에 맞는 사실이 없으면 그 칸은 `[확인 필요]`로 남긴다.

## A. 발견 → 수치 → 가격 → 총평 (약 20초, 17~18컷)
근거: 갈미조개 칼국수 릴스 (조회 120만)

| 시간 | 내용 | 말 틀 |
|---|---|---|
| 0~3초 | 시그니처 한 그릇 클로즈업 | "[지역]에서 [수식어] [메뉴]집을 발견했습니다." |
| 3~8초 | 재료·양 컷 | "[시그니처]가 [수치]나 들어가서 이렇게 [푸짐한 표현]인데요." |
| 8~12초 | 가격 | "가격이 [가격]원밖에 안 해요." |
| 12~17초 | 사이드·특징 | "심지어 [사이드·특징]까지 있어서" |
| 17~20초 | 총평 + 판결 | "[한 줄 총평]." → 판결 도장 |

## B. 웨이팅 → 메뉴 2개 → 팁 (약 17초, 6컷)
근거: 강북구 짬뽕 릴스 (조회 19만, 소형 계정)

| 시간 | 내용 | 말 틀 |
|---|---|---|
| 0~3초 | 줄 선 외관 | "[날씨·요일]에도 줄 서는 이곳은 [지역]에서 [메뉴]로 유명한 곳인데" |
| 3~8초 | 메뉴 1 | "우선 [메뉴1]은 [감상]." |
| 8~14초 | 메뉴 2 | "[메뉴2]는 [양·식감·계절 어필]." |
| 14~17초 | 팁 | "[웨이팅 팁]이니 참고하세요!" → 판결 도장 |

## C. 점수제 (약 20초, 13컷, 내레이션 없이 BGM + 자막)
근거: 용산 고깃집 릴스 (조회 18만)

| 시간 | 내용 | 자막 틀 |
|---|---|---|
| 0~3초 | 대표 컷 | "[소문·추천]난 [지역] [메뉴]집 제 점수는 과연...?" |
| 3~15초 | 항목별 컷 | "[항목] 좋다 +10점" / "[감상] +20점" |
| 15~20초 | 총평 | "[한 줄 총평]" + "같이 갈 친구 태그하기" → 판결 도장 |

점수 항목은 사실에 맞게 고른다. (서비스, 분위기, 맛, 가성비)

## D. 가성비 한 상 + 실용 정보 (약 30~35초, 12컷)
근거: 백반집 릴스 (조회 19만, 팔로워 7천)

| 시간 | 내용 | 말·자막 틀 |
|---|---|---|
| 0~4초 | 한 상 | "이게 다 나온다고?" |
| 4~12초 | 줄·시간 | "[요일] [시간]인데 이렇게 줄 서 있다고?" |
| 12~18초 | 가격 | "[인원]이서 [가격]원 / [주문 구성]" |
| 18~26초 | 감탄 컷 3개 | "[감상]!" (짧게) |
| 26~32초 | 실용 정보 | 칩: 셀프 / 혼밥 가능 / 재료 소진 시 마감 |
| 32~35초 | 영업시간 안내문 줌인 | "영업시간 보시고" → 판결 도장 |

## E. 제품 사용기 (약 20초)
근거 약함(★). 위 구조 A·C를 제품에 맞게 바꾼 것. (검증형 G, 경고형 H도 제품에 쓸 수 있다.)

| 시간 | 내용 | 말 틀 |
|---|---|---|
| 0~3초 | 제품 + 가격 | 훅 P1~P4 |
| 3~8초 | 써보는 장면 | "[기간] 써봤는데 [사용 결과]." |
| 8~13초 | 장점 | "좋았던 건 [장점 1], [장점 2]." |
| 13~17초 | 아쉬운 점 | "아쉬운 점은 [단점]이에요." |
| 17~20초 | 판결 | "[가격]원 기준으로 [한 줄 결론]." → 구매 추천 O/X |

## F. 행사·이벤트 정보 (10~17초, 5~12컷)
근거: 멕시카나 10초 5컷 / 엽떡데이 13초 원테이크 / 쓱데이 17초 12컷

| 시간 | 내용 | 말 틀 |
|---|---|---|
| 0~3초 | 혜택·가격·마감 중 하나를 시각으로 | 훅 I1~I3, I7 ("[조건]하면 [혜택] 공짜?!" / "이번 주 [요일]까지!") |
| 3~8초 | 조건·대상 + 혜택 상세 | "[대상]이 [조건]이면 [혜택]이에요." |
| 8~13초 | 참여 방법 | "[앱·매장]에서 [방법]으로 주문하면 돼요." |
| 13~17초 | 기간 + 증거 + 행동 | "[날짜]까지예요. [영수증·현장 컷]" → "친구한테 공유!" |

- 정보 순서는 **혜택 → 조건 → 방법 → 기간** (기간을 훅에서 먼저 말하는 경우도 많다).
- **증거 컷**을 하나 넣는다: 영수증, 앱 화면, 줄 선 모습, 가격표.
- 끝은 "놓치기 전에 방문해 보세요", "공유 고고", "친구 태그" 중 하나.
- 캡션 구조: `(공유·저장)` 첫 줄 → `📌 이벤트 기본 정보` → `▪️ 기간` `▪️ 대상` `▪️ 혜택` `▪️ 방법` → 기준일 → 공식 출처 확인 안내.

## G. 꿀팁 검증형 (30~60초 또는 20초 요약, 10~12컷)
근거: 밤껍질 릴스 57초 12컷 (조회 130만, 팔로워 532명)

| 시간 | 내용 | 말 틀 |
|---|---|---|
| 0~3초 | 문제 + 호기심 | "[방법]? 진짜 될까?" / "[방법]이 있어서 해 볼 건데요." |
| 3~25초 | 단계별 시도 | 자막 "[재료] [양]" → "[동작]" (한 컷 1단계) |
| 25~40초 | 기다림 + 긴장 | "두근두근~", "열어볼게요." |
| 40~50초 | 결과 확인 | "오~ 비주얼은? 통과!" |
| 50~57초 | 반전·성공 판정 | "[결과 증명 컷]. 와우 성공!" → **성공 O / 실패 X** |

- 말투: "~해 볼 건데요 / ~할 거예요 / ~열어볼게요" 구어체 + 감탄 "음~ 오~".
- 단계 자막은 **재료와 양을 숫자로** 쓴다. (설탕 한 숟가락, 물 한 대접)
- 20초 요약판은 단계를 3개로 줄이고 결과 컷을 앞에 둔다.

## H. 꿀팁 경고·비추천형 (7~15초, 원테이크 가능)
근거: 다이소 치실 릴스 7초 1컷 (조회 180만)

| 시간 | 내용 | 말·자막 틀 |
|---|---|---|
| 0~3초 | 직접 써보는 장면(표정 포함) | "[상황]이라 [제품] 샀는데 **절대 쓰지 마세요**" |
| 3~8초 | 구체적 이유 | "[증상 1] 아니면 [증상 2]예요." / "진짜 [특징]해서" |
| 8~12초 | 대안 또는 마무리 | "[대안]은 괜찮았어요." 또는 말을 끊고 컷 종료(루프) |

- **이유를 몸으로 보여준다.** 직접 사용하는 컷이 필수.
- 상표·가게 비방, 과장은 금지. 확인 가능한 사실과 본인 경험만.
- 자막은 한 박스에 3~4줄 고정 자막으로 써도 된다.

## I. 꿀팁 목록형 (20~35초)
근거: 변호사 3가지(110만), 세탁 꿀팁 모음(100만)

| 시간 | 내용 | 말·자막 틀 |
|---|---|---|
| 0~3초 | 목록 선언 | "[신분·상황] [주제] N가지" |
| 3~25초 | 항목 N개 (항목당 5~7초) | "첫째, [팁]" + 시연 컷 + 한 줄 이유 |
| 25~30초 | 저장 유도 | "저장해두고 [상황]에 써보세요." |

## J. 동선·장소 꿀팁 브이로그형 (약 20초, 원테이크 이동 컷 + 음성 + 자막) — 사용자 직접 제작본에서 흡수
근거: 안성스타필드 아쿠아필드 주차꿀팁 (사용자 본인 릴스, 20.8초, 자막 17개, 평균 1.2초/자막). 조회수 데이터는 없다. 구조·리듬만 흡수했다.

| 시간 | 내용 | 말·자막 틀 |
|---|---|---|
| 0~2초 | **웃음 반전 훅** (결과를 먼저, 이유는 뒤로) | "여기에 주차하고 / 둘째 / 생길뻔 했다" (끊어서 3자막) |
| 2~6초 | 상황 + 약속 | "주말에 [장소] 가서 / 와이프한테 칭찬받는 / [목적지] 최단 동선 꿀팁 푼다" |
| 6~16초 | **이동 순서대로 한 동작에 한 자막** | "지하주차장으로 / 들어가서 / B1층 5번홀 / 근처에 주차 / 주차한 구역은 / 꼭 사진찍어 / 못찾으면 혼나 / 그다음 엘베 입구 ㄱㄱ / 3층ㄱㄱ / 3층으로 올라가면 / 바로 아쿠아필드 도착" |
| 16~17초 | 성공 컷 (목적지 간판) | "오늘도 성공!" |
| 17~21초 | **훅 콜백** + 덤 혜택 | "여기에 주차하고 / 와이프한테 안혼난다 / 그리고 / 주차 꽁짜다" |

규칙
- 첫 자막과 끝 자막 앞부분을 **같은 문장("여기에 주차하고")으로 맞춘다.** 처음엔 웃음, 끝엔 안도로 뜻이 바뀐다.
- 장소 이름(B1층 5번홀, 3층)은 **그 장소가 화면에 보이는 순간에** 자막으로 띄운다.
- 말투: 반말 구어체, 짧은 명령("꼭 사진찍어", "ㄱㄱ", "~푼다"), 아내 언급 유머. 비하·과장은 쓰지 않는다.
- "~ 꽁짜다" 같은 혜택은 **조건을 확인한 뒤에만** 쓴다. 미확인이면 `[확인 필요: 주차 무료 조건]`.
- 번호·층·기둥 문자는 **현장 사진/영상에서 확인된 것만** 쓴다.

## 구조 선택 가이드
- 가격·양이 강점 → A 또는 D
- 줄 서는 곳, 시간 정보가 핵심 → B 또는 D
- 정리된 감상·평가가 많다 → C
- 사실이 거의 없다 → B의 틀에서 확인된 컷만 쓰고 짧게(15초) 만든다
- 행사·할인·이벤트 → F
- 장소 이동 동선·주차·입장 꿀팁을 직접 찍었다 → J(동선 브이로그형)
- 직접 해본 방법이 있다 → G(검증형), 단점이 확실하면 H(경고형), 항목이 여러 개면 I(목록형)
