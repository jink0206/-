## 공통 패턴
1. 첫 3초에 가격·양·웨이팅 중 하나를 시각+자막으로 증명한다.
2. 숫자를 쓴다: 500g, 12,000원, 22,000원, 최소 30분.
3. 컷은 1~3초. 자막은 1~3단어씩.
4. 실용 정보를 단문으로 준다: 셀프, 혼밥 가능, 재료 소진 시 마감, 오픈런.
5. 끝은 총평, 팁, 영업시간, 태그 유도 중 하나로 짧게 닫는다.
6. 말투: "~했습니다 / ~인데요 / ~안 해요 / ~참고하세요" 혼용. 강조어 "진짜, 무려, 엄청".

## 한계

- 4개 중 2개는 TTS/BGM 중심이고, 1개는 현장음이다. 우리 계정은 직접 말하는 방식도 시험해 볼 만하다.
