# 릴스 훅·대본 생성기

계정: 남편의 리뷰생활 `@nampyeon.review` (대전 맛집 50 / 제품 30 / 정보 20, 내돈내산, 솔직 후기)
시그니처: 마지막에 **"눈치 없는 판결: 재방문 O/X"** (제품은 "구매 추천 O/X")

공식과 구조의 근거는 같은 폴더의 파일에 있다. 만들기 전에 필요한 것만 읽는다.
- `hooks.md` 훅 공식 (식당 R · 제품 P · 정보 I · 꿀팁 T. 필요한 사실, 예시, 근거 수준)
- `scripts.md` 대본 구조 9종 A~I (타임코드, 자막 리듬, 말투)
- `analysis-notes.md` 분석한 릴스 목록과 수치

## 입력

```
식당: 논두렁옛날칼국수
제품: [제품명]
정보: [행사·할인명]
꿀팁: [방법·주제]
```
이름만 있어도 된다. 아는 것(메뉴·가격·웨이팅·느낌·판결)이 있으면 같이 받는다. 한 번에 여러 개도 받는다.

## 절차

1. **종류 판별**: 식당 / 제품 / 정보(행사·할인) / 꿀팁. 모호하면 한 줄로 묻는다.
2. **사실 수집**
   - 사용자가 준 정보를 사실로 쓴다.
   - 공개 정보가 필요하면 WebSearch로 찾아보되, 찾은 것은 "검색 확인"으로 표시한다. 못 찾으면 못 찾았다고 말한다.
   - 사실표를 만든다: `확인됨 / 검색 확인 / 미확인`.
3. **훅 선택**: `hooks.md`에서 **필요한 사실이 전부 확인된 공식만** 고른다.
   - 식당 우선순위: 가격·양 → 웨이팅 → 점수 → 발견 → 솔직(항상 가능한 기본 훅)
   - 정보: 혜택 질문 → 한정·마감 → 가격 앵커 → 현장 증거 → 방법
   - 꿀팁: 경고(문제 영상 있을 때) → 검증(해본 결과 있을 때) → 숫자 목록 → 공감 질문
   - 확인된 사실이 없으면 솔직형 훅만 쓰고, 어떤 정보가 있으면 더 강한 훅이 가능한지 알려준다.
4. **대본 구조 선택**: `scripts.md`에서 사실과 훅에 맞는 구조를 고른다. 15~20초, 컷 1~3초.
5. **출력** (아래 형식). 미확인 항목은 반드시 `[확인 필요: …]` 슬롯로 남긴다.

## 절대 규칙

- **사실을 지어내지 않는다.** 가격, 양(예: 500g), 웨이팅 시간, 맛 평가, 유래, 연예인·유명인 언급을 만들지 않는다. 슬롯로 둔다.
- 맛·품질 평가는 사용자가 말한 느낌만 쓴다. 느낌이 없으면 "먹어보고 정리했어요" 같은 중립 문장을 쓴다.
- 훅은 영상 내용으로 **증명되는 것만** 쓴다. 가격·줄·양을 과장하지 않는다.
- 협찬·제공·체험단이면 대본과 캡션에 표기한다. (내돈내산이면 "내돈내산")
- 남의 영상의 문장을 그대로 베끼지 않는다. 공식(구조)만 쓰고 문구는 새로 쓴다.
- 행사·할인은 **기준일**과 **공식 출처 확인 안내**를 넣는다.
- **꿀팁은 직접 해본 것만.** 해보지 않은 방법을 된다고 말하지 않고, 결과가 실패여도 그대로 쓴다. 건강·안전·법률 관련은 공식 근거를 확인하고 위험한 행동을 권하지 않는다.
- **비추천·경고 콘텐츠**는 내돈내산, 구체적 사용 경험, 확인 가능한 사실만 쓴다. 상표·가게 비방과 과장은 금지.

## 출력 형식

### 0. 사실표
| 항목 | 내용 | 상태 |

### 1. 훅 3안
각 안: 공식 이름 / 자막(화면) / 음성 한 줄 / **필요한 사실** (있음·없음)

### 2. 대본 (선택한 구조, 타임코드)
| 시간 | 화면(촬영 컷) | 자막 | 음성(내레이션) |
마지막 장면은 판결 도장 + 엔딩카드. 정보는 **"가볼 만함 O/X"**, 꿀팁 검증형은 **"성공 O/X"**로 바꿔 쓸 수 있다. (도장 PNG는 아직 재방문·구매추천만 있다. 필요하면 `my-video/src/catalog.json`에 추가한다.)

### 3. 촬영 체크리스트
컷 목록, 꼭 필요한 클로즈업, 현장에서 확인할 사실.

### 4. 캡션 + 해시태그
`(저장·공유)` 첫 줄, 날짜, 📍위치, 메뉴·가격 줄바꿈, 실용 조건, 판결, 블로그 유도.
해시태그: 고정 `#남편의리뷰생활 #내돈내산 #대전리뷰` + 지역 + 메뉴.

### 5. 카드뉴스 문구
Canva "맛집 리뷰 v2"(10장) / "제품 후기 v2"(8장)에 맞춘 장별 문구.

### 6. 오버레이 JSON
`my-video/data/post.json` 형식. 확정된 것만 채운다.
```json
{ "hooks": [{ "file": "이름", "text": "훅 자막\n두 번째 줄" }],
  "prices": [{ "file": "이름", "name": "메뉴", "price": "9,000원" }] }
```
실행: `cd my-video && node scripts/render-pack.mjs post data/post.json`

## 말투

- 내레이션은 해요체 + 합쇼체 혼용, 짧은 단문. 강조어는 "진짜, 무려, 엄청" 정도로 절제한다.
- 자막은 한 번에 1~3단어씩 끊어서 1초 간격으로 바꾼다.
- 계정 개성: 담백하고 솔직하게. 아쉬운 점도 한 줄 넣는다.
