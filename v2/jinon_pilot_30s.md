# 파일럿 #01 오늘 누가 괜찮냐고 물어봤어? (안부)

권장 업로드: 11/17(화)

## 제목 후보
1. 오늘 누가 괜찮냐고 물어봤나요
2. 다 챙긴 밤, 내 안부는
3. 너무 괜찮아 보여서
4. 안부를 묻는 쪽이 된 어른
5. 오늘은 제가 물을게요

**추천 제목**: 오늘은 제가 물을게요
**핵심 메시지**: 아무도 안 물은 건, 안 괜찮아서가 아니라 너무 괜찮아 보이게 버텨서였을지도 모른다.

## 후킹 (A/B)
| | 화면 문구 | 첫 내레이션 |
|---|---|---|
| A 호명 | 오늘 누가 / 괜찮냐고 / 물어봤나요? | "오늘 누가, 괜찮냐고 물어봤나요?" |
| B 역설 | 안부를 묻는 쪽이 / 되는 줄은 / 몰랐다 | "안부를 묻는 쪽이 되는 줄은 몰랐어요." |

## 한국어 내레이션 (공백 포함 A 115자 / B 118자, 목표 100~120자)
> (후킹 A 또는 B)
>
> 오드리 로드는 말했어요. 나를 돌보는 건 나를 지키는 일이라고.
>
> 다 챙긴 밤, 내 안부는 아무도 안 물었죠.
>
> 너무 괜찮아 보여서일지도요.
> (…)
> 오늘은 제가 물을게요. 괜찮으세요?

| 0:03~0:11 | 명언 | 동일 (느린 줌 없이) |
| 0:11~0:18 | 장면 | 불 꺼진 거실 창가 (손촬영 또는 스톡) |
| 0:18~0:22 | 반전 | 동일, 대사 앞 1.5초 정적 |
| 0:22~0:30 | 마지막 문장 | 서서히 암전, 로고 |

## 영어 자막
- A: Did anyone ask if you're okay today?
- B: I never thought I'd be the one asking everyone else.
1. Audre Lorde wrote, / "Caring for myself is not self-indulgence, it is self-preservation."
2. After taking care of everyone, / no one asked about me.
3. Maybe because I looked so fine.
4. Today, I'll ask. / Are you okay?

# 파일럿 #03 괜찮은 척, 오늘은 쉬어도 돼요

4. 당신도 플러그를 뽑아야 해요

**핵심 메시지**: 쉰다는 건 멈추는 게 아니라 다시 켜질 준비를 하는 일이다.
