# 문체·구성 가이드 (운영 중인 글 4편에서 추출)

## 이미 잘 하고 있는 것 — 유지
- 도입: 공감 질문 → "이 글에서 정리해 볼게요" 3~6줄. 독자가 지금 궁금한 걸 바로 찌른다.
- 소제목: `번호. 핵심키워드 + 질문/단정`. 소제목에 검색어가 들어간다.
- 섹션마다 사진 1장 (`[사진 N. 설명]`). 섹션 7개 안팎.
- 단정 뒤에 "물론 ~는 개인차가 있어요" 식 단서를 달아 과장하지 않는다.
- 마지막은 요약 + 독자 질문(댓글 유도), 해시태그 10개 안팎.
- 이슈 글은 "모두 해당되는 건 아니다"를 분명히 한다. 신뢰도에 좋다.

## 보완할 것 — check_post.py 가 잡아 준다
1. **검색 의도의 1순위 정보가 빠진 글이 있다.**
   - 행사 글: 기간·장소·체험비·예약 여부 (본문에 "현장에서 확인하세요"만 있으면 이탈 원인)
   - 맛집 글: 영업시간·브레이크타임·휴무, 맛 묘사
   - 모든 사실 글: `기준일`
2. **맛집 글에 맛 묘사가 없다.** 메뉴마다 "맛·식감·간·양" 1~2문장 + 아쉬운 점 1개.
3. **추측·전언 표현이 많은 글** ("~해 보여요", "~일 것 같아요", "후기가 있는 곳"). 직접 가 본 글처럼 읽히지 않는다.
   직접 방문하지 않았다면 "후기"라고 쓰지 말고 정보 정리 글로 표기한다.
4. **모든 글이 같은 7단 구조·같은 말버릇**(~잖아요, ㅎㅎ, "다만", "특히")이다.
   글마다 틀이 똑같으면 템플릿 글로 묶일 위험이 있다. 이슈 글은 6단, 짧은 팁 글은 4단처럼 길이와 구조를 바꾼다.
5. 사진: 글마다 직접 찍은 사진이 최소 3장은 있어야 한다. 이미지 캡처·보도 사진은 출처 표기.

## 이슈·시의성 글 규칙
- 수치·기관명·날짜는 출처 링크로 확인한 것만 쓴다. 모르면 빼거나 "확인 필요"로 둔다.
- 마지막에 `출처 및 기준일`.
- 시한이 있는 글(수능, 행사 등)은 종료 후 "종료되었습니다" 문구를 상단에 추가하거나 내용을 갱신한다.
