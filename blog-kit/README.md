# 블로그 반자동 키트 (여행 · 맛집 · 정보 · 리뷰 · 이슈)

자동 발행은 하지 않습니다. 초안까지만 자동화하고, 사진·경험·발행은 사람이 합니다.

## 흐름
1. `topics.csv`에서 주제를 고른다 (`verify` 열은 발행 전 직접 확인할 항목, `publish_by`는 시한). 카테고리: travel / restaurant / info / review / issue(시의성 이슈).
2. 초안 생성: `python3 tools/new_post.py review "제목" --keyword "핵심키워드"`
3. Claude에게 `posts/` 초안을 채우게 한다. 단, 방문 일시·맛·사용감 등 `[[ ]]`는 본인 경험으로 직접 채운다.
4. 점검: `python3 tools/check_post.py posts/<파일>.md` — ERROR가 0이 될 때까지 수정.
5. 직접 찍은 사진을 `[사진: ]` 자리에 넣어 네이버 에디터에서 발행.
6. 일주일 뒤 조회수·체류시간이 좋았던 글의 주제를 `topics.csv`에 반영.

문체 규칙과 보완점은 `STYLE.md` 참고.

## 원칙
- 협찬·원고료·제품 제공은 `sponsored: true`로 바꾸고 글 상단에 표기 (표시광고법 대상).
- 가격·운영시간·제도 정보는 작성일 기준으로 쓰고 공식 출처를 확인.
- 글마다 직접 겪은 내용 2개 이상. 그게 없으면 발행하지 않는 편이 낫다.
- 하루 발행량을 무리하게 늘리지 말 것. 품질 저하가 노출 손실로 돌아온다.
